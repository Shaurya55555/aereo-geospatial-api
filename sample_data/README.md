# Sample data

Generated by `python scripts/make_samples.py`. Shapes are built in metres in UTM zone 43N
near Jaipur, so their true sizes are known, then converted to longitude/latitude.

Upload any of these at `POST /api/files/` (or through `/docs`).

| File | CRS in file | Expected result |
| --- | --- | --- |
| `survey.kml` | EPSG:4326 (KML) | 6 features, measured in `EPSG:32643`. Status `COMPLETED_WITH_ERRORS` (1 failed). |
| `parcels_wgs84.zip` | EPSG:4326 | 3 parcels: 1,000,000 / 250,000 / 40,000 m2. Measured in `EPSG:32643`. |
| `parcels_utm.zip` | EPSG:32643 | Same 3 parcels. The file's own UTM CRS is kept as the measurement CRS. |
| `parcels_webmercator.zip` | EPSG:3857 | Same 3 parcels. Re-projected to `EPSG:32643` first, because Web Mercator inflates areas by about 25% at this latitude. |
| `no_prj.zip` | none | `422`: no `.prj`, so the CRS is unknown and is not guessed. |

## `survey.kml` features

| Name | Geometry | Expected |
| --- | --- | --- |
| Plot 1km square | Polygon | `area_m2` about 1,000,000 |
| Plot with hole | Polygon with a 500 m x 500 m hole | `area_m2` about 750,000 |
| Two small plots | MultiPolygon | `area_m2` about 20,000 (total) |
| Road | LineString | `length_m` about 4,000 |
| Gate | Point | `NO_MEASUREMENT_REQUIRED` |

Values match the true sizes to within about 0.001% because the shapes sit near the centre of the zone.
